# Victoria 3 Lite

A performance mod for Victoria 3 (game version 1.15.1). Made for people who need the game to run on a potato computer, or who just want to finish a game in one afternoon.

## Design
- The gameplay loop stays: you still build an economy, run politics and laws, and fight diplomacy and wars.
- Anything the loop does not depend on may be simplified or removed for speed.
- Larger changes come with game rules so players can turn them off.

## Planned changes
- **Culture and religion unification** (on by default, with an opt-out game rule): every pop becomes one culture and one religion at game start, so pops merge and the simulation has far less to calculate.
- Simpler AI scoring, fewer countries, cheaper pop qualification checks, lighter portraits, and fewer costly alerts and progress bars. Each change is measured before it ships.

## Status
Early development (v0.1).

Done:
- **Pop Cultures** game rule with four settings:
  - **One culture** (default): every pop and every country's primary culture becomes Human.
  - **Heritage groups**: 11 cultures, one per heritage group (European, East Asian, African...).
  - **Heritages**: about 100 cultures, one per heritage (Germanic, Gallic, East Slavic...).
  - **Original cultures**: vanilla.
  Merged cultures are built on an existing vanilla culture (see `docs/culture_merging.md`), so its content still works, and show the group or heritage name on screen. Countries' primary cultures and homelands merge with them. Generated by `tools/gen_culture_merge.py`.
- **Pop Religions** game rule with four settings:
  - **One faith** (default): every pop and country follows a new neutral religion, the Faith. It is not Atheist, so clergy work normally.
  - **Heritage groups**: four religions (Abrahamic, Eastern, Naturalistic, Non-Spiritual), built on Catholic, Confucian, Animist and Atheist.
  - **Heritages**: seven religions (Christian, Islamic, Jewish, Dharmic, Taoic, Indigenous, Materialist), built on Catholic, Sunni, Jewish, Hindu, Confucian, Animist and Atheist.
  - **Original religions**: vanilla.
  Merged religions keep the underlying vanilla religion, so its events and journal entries still work, and show the group or heritage name on screen through customizable localization.
- **Pop Consolidation** game rule (default: on). At game start every pop in a state takes the state's largest culture and largest religion. Works on top of the other two rules; most useful with Original cultures or religions.
- **Migration** (always on): market migration settings from the United Nations of Earth mod. Migrants go to the single most attractive state in their market, and only states with near-zero pull send emigrants. Mass migration between countries is unchanged. See `common/defines/99_vl_migration_defines.txt`.
- **Pop merging** (follows vanilla's pop consolidation rule, renamed "Pop Merge (Performance)"): pops with up to 500,000 workforce can merge with others of the same profession in the same building, instead of vanilla's 10-100. See `common/defines/99_vl_pop_merge_defines.txt`.
- **Costly Alerts** game rule (default: off). Skips the "low expected standard of living in state" alert, which is expensive to check. Alerts cannot be partially overridden, so the mod ships a full copy of vanilla's `00_alert_types.txt`.

Not yet tested in game. Test checklist:
1. Start a new game with the mod on and both rules at their defaults. Check `logs/error.log` for lines mentioning `vl_` or `alert_types`.
2. Open a few countries: primary culture should be Human, state religion the Faith, and pops should show no culture or religion discrimination.
3. Start games with Pop Religions on Heritage groups and on Heritages. Check that religion names read Abrahamic / Christian and so on everywhere (state panel, pop list, country panel, tooltips), and that no screen shows raw text like `[GetGlobalVariable...]`. Check the main menu and lobby too. With Original religions, names must read as vanilla.
4. Start games with Pop Cultures on Heritage groups and on Heritages: France's primary culture should read European / Gallic, homelands should cover the merged cultures' old homelands, and culture names should read correctly everywhere.
5. With Pop Cultures and Pop Religions on Original and Pop Consolidation on: every state should show a single culture and a single religion, the one that was largest before.
6. With Costly Alerts off, the low standard of living alert should never appear; with it on, it should.
7. Migration: in the market panel or a state's migration tooltip, immigrants should go to one top state at a time; watch the Tick Task List for ProcessEconomicMigration lock times.
8. Pop merging: after a few in-game years, the number of pops (Tick Task List MergeSmallPops activity, or pop counts in large states) should be much lower than vanilla. Watch unemployment: unemployed pops under the merge size with a poor worker ratio are turned into dependents.
9. Run to the benchmark date and time 50 s at speed 5. Compare against the same rules set to "Original".

## Optional ideas (not built)
- **Keep original primary cultures.** The culture rules currently replace each country's primary cultures. Adding the new culture without removing the old ones would keep vanilla's culture-based map colors (Great Qing turns red without Manchu), dynamic country names (4 color rules, 18 name rules check primary cultures) and nation forming working, at almost no cost, since the old cultures have no pops.
